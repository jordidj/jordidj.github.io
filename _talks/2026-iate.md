Seminar at the Instituto de Astronomía Teórica y Experimental, Universidad Nacional de Córdoba, Argentina.

__Abstract.__ The open-source Legolas code is a linear MHD code that quantifies all the natural oscillations and instabilities of a user-defined force-balanced state, for Cartesian or cylindrical geometries. In order to paint a realistic picture, the code features a modular implementation of most MHD terms, from flow and external gravity to non-ideal terms such as resistivity and thermal effects. In this seminar, I will present the Legolas code and highlight a selection of its features, including the new GIMLI framework for connecting to non-linear simulations with MPI-AMRVAC. Finally, I show some results of the application of the Legolas code to the study of current sheets in solar contexts.
